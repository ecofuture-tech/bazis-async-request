# bazis-async-request 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (setup, the client protocol, `require_async` and the
  security rules) and `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md`
  of Bazis).
- New system checks (`manage.py bazis_doctor`):
  - `async_request.W001`: Kafka is not configured, so the requests sent with
    `X-Async-Background` are executed synchronously;
  - `async_request.E001`: the route of the results (`bazis.contrib.async_background.router`)
    is not registered, so `AsyncRequestMiddleware` fails on every HTTP request.
